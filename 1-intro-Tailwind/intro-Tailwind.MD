     ***WHAT IS CDN***

     मान लो एक वेबसाइट का main server USA में है।

USA का user वेबसाइट खोलेगा → जल्दी load होगी।
India का user वेबसाइट खोलेगा → थोड़ा समय लगेगा।

CDN क्या करता है?

यह वेबसाइट की files को दुनिया के अलग-अलग servers पर store कर देता है।

फिर जब India का user वेबसाइट खोलेगा, तो CDN उसे India या उसके नज़दीकी server से data भेजेगा।

इससे website fast load होती है। ⚡


***CDN के फायदे ✅**

Website Speed बढ़ाता है
Server Load कम करता है
Better User Experience देता है
Global Users के लिए Fast Performance
Website की Reliability बढ़ाता है

   ***WHAT IS PORT : NO ***

   Port Number एक logical number होता है जो कंप्यूटर में किसी specific application या service की पहचान करता है।

जब data इंटरनेट से आपके कंप्यूटर पर आता है, तो IP Address बताता है कि data किस computer तक जाना है, और Port Number बताता है कि उस computer के किस application तक जाना है।

**Interview Definition 🎯**

Port Number एक numerical identifier होता है जो किसी computer पर चल रही specific network service या application को identify करता है। IP address destination computer को identify करता है, जबकि port number destination application को identify करता है।
